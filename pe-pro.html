Galeria Terrazzo : desenvolvimento de website informativo

São José dos Campos, SP, 2026.

Projeto de desenvolvimento web voltado à apresentação do material terrazzo, suas características, aplicações e possibilidades estéticas. O website reúne conteúdo informativo, páginas institucionais e uma galeria visual de referências, com navegação entre seções e apresentação de imagens em carrossel.

Descrição técnica: desenvolvimento de interface web responsiva, estruturação de páginas com HTML e CSS, estilização com Tailwind CSS, implementação de interações com JavaScript e estruturação da aplicação com Python e Flask.

Notas: projeto desenvolvido com organização de templates, arquivos estáticos e rotas de aplicação. Inclui configuração de ambiente de execução e experimentação de implantação em servidor AWS EC2.

Tecnologias: HTML5; CSS3; JavaScript; Python; Flask; Tailwind CSS; Git; GitHub; AWS EC2.

Assuntos: Desenvolvimento web; Frontend; Backend; Interfaces web; Design responsivo; Aplicações Flask.
